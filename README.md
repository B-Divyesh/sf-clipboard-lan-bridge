# Clipboard LAN Bridge

Clipboard LAN Bridge is a small desktop utility for deliberately handing short text and links between your own nearby computers. It uses LAN discovery, explicit code comparison and receiver approval, X25519 key agreement, and authenticated XChaCha20-Poly1305 encryption. There is no cloud relay, account, clipboard watcher, file transfer, or telemetry.

The current v1 desktop release supports Linux, macOS, and Windows. A phone companion is not included yet; mobile background and local-network permission work is tracked as a post-v1 gap rather than hidden behind a web demo.

## Who it is for

People who currently message themselves or maintain a shared text file just to move a URL, address, command, or short note across nearby machines—and want each handoff to be visible and short-lived.

## Safety model

- Discovery broadcasts only a random device ID, chosen device name, public key, and local port.
- Both devices display a six-character fingerprint derived from their public keys; the receiver must approve.
- Paired peers derive a shared X25519 secret. Transfer bodies are authenticated and encrypted with XChaCha20-Poly1305.
- Only valid UTF-8 text up to 32 KB is accepted. Items expire after 2, 10, or 60 minutes.
- Clipboard reads and writes occur only after an explicit button press.
- Identities and paired public keys live in the operating system's app-data directory. Active tickets stay in memory.

This is a personal LAN tool, not a replacement for a password manager. Pair only on networks you trust and compare the displayed code.

## Run locally

Requirements: Node.js 22+, Rust stable, and the [Tauri 2 prerequisites](https://v2.tauri.app/start/prerequisites/) for your operating system.

```sh
npm ci
npm run tauri dev
```

Run just the responsive product/download site with `npm run dev:site`.

## Test and build

```sh
npm test
npm run build
```

`npm test` runs unit tests, Chromium accessibility/responsive tests, and Rust crypto/domain tests. `npm run build` writes the Tauri webview to `dist/app/` and the deployable static site—with `index.html` at its root—to `dist/site/`. Build a local desktop package with `npm run tauri build`.

## Install and release

Release packages are generated by GitHub Actions for macOS (Apple Silicon and Intel), Windows, and Linux. All v1 packages are unsigned; on macOS right-click the app and choose **Open**, and on Windows confirm the publisher warning.

```sh
curl -fsSL https://clipboard-lan-bridge.sociobot.in/install.sh | sh
```

Windows PowerShell: `irm https://clipboard-lan-bridge.sociobot.in/install.ps1 | iex`

Both installers resolve the current package from `latest.json` and verify SHA-256 before installing. You can also use the [latest release](https://github.com/B-Divyesh/sf-clipboard-lan-bridge/releases/latest).

Push a `v*` tag or run the **Release desktop apps** workflow manually. The matrix builds each native target, publishes packages through `softprops/action-gh-release`, and adds `SHA256SUMS` plus `latest.json`.
