How it works

Pair, send, and copy

  1. 01

    Pair with a code

    Both screens show the same code. The receiving device must approve before pairing completes.

  2. 02

    Choose what leaves

    Paste or type text, pick a device, then choose Send text. The clipboard is never monitored.

  3. 03

    Copy before it expires

    The encrypted text arrives over your local network. Copy it before its time runs out.
