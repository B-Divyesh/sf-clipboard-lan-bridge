Privacy and local data

We do not receive the text you transfer. The app has no accounts, advertising, analytics, telemetry, or cloud relay.

Data on your devices

The desktop app stores your device name, private keys, paired public keys, and any license token. Active tickets stay in memory and disappear after expiry.

The phone companion stores its private pairing key and desktop public key in that phone browser. It loads directly from your computer on the local network.

Network visibility

The desktop app broadcasts a random device identifier, chosen name, public key, and local port. Other copies use this information for discovery.

No clipboard content is broadcast. Network administrators may see the service announcement, but paired transfer text is encrypted.

Clipboard access

The clipboard is read only when you choose “Paste from clipboard.” It is written only when you choose “Copy text.”

Purchases

Sociobot and Dodo process Route pass purchases under their own policies. The app sends only your license token to the Sociobot verification endpoint.

A checkout return stores the license in this website's local storage until you copy it. The website does not share that storage with the desktop app.

Website

The site has no advertising or analytics cookies. Its host may keep ordinary security logs, including IP address, user agent, and request time.

The download page requests public release information from GitHub. The demo makes no off-origin requests and stores samples only for the browser session.

Your choices

You can forget a peer, delete an arrival, remove a license, clear the phone browser's site data, or uninstall the app.

For privacy questions, email privacy@sociobot.in.
