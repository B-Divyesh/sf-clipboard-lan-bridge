How it works

Pair, send, and copy

  1. 01

    Pair with a code

    Both screens show the same code. The receiving device must approve before a route exists.

  2. 02

    Choose what leaves

    Paste or type one text item, pick a device, then press Send. The clipboard is never monitored.

  3. 03

    Copy before expiry

    The encrypted ticket arrives over your LAN. Copy it before its expiry time.

Privacy limits

Only the text you choose

Clipboard LAN Bridge handles UTF-8 text and web links only. It does not read clipboard changes, images, files, or password autofill data.
