Privacy and local data

We do not receive the text you transfer. The app has no accounts, advertising, analytics, telemetry, or cloud service.

Data on your devices

The desktop app stores your device name, private keys, and paired public keys. Active transfers stay in memory and disappear after expiry.

The phone companion stores its private pairing key and desktop public key in that phone browser. It loads directly from your computer on the local network.

Network visibility

Nearby devices use local network discovery. No clipboard content is broadcast. Paired transfer text is encrypted.

Clipboard access

The clipboard is read only when you choose “Paste from clipboard.” It is written only when you choose “Copy text.”

Website and purchases

The site has no advertising or analytics cookies. Its host may keep ordinary security logs, including IP address, user agent, and request time.

The download page uses release information shipped with this site. Public pages contact only this product website.

The demo stores samples only for the browser session.

The website saves a returned license token in this browser for desktop restore. The desktop app sends a pasted token to Sociobot only when you choose Verify license.

Your choices

You can forget a peer, delete an arrival, clear the phone browser's site data, or uninstall the app.

For privacy questions, email privacy@sociobot.in.
